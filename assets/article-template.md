## Pre-publish checklist

### SEO
- [ ] Keyword in title (start)
- [ ] Keyword in slug
- [ ] Keyword in excerpt
- [ ] Keyword in H1 + 2+ H2s
- [ ] Keyword in first 100 words
- [ ] Density 0.8-1.5%
- [ ] 1500-2500 words (3000+ for pillar)
- [ ] 3-5 internal links
- [ ] 1-2 external authoritative links
- [ ] Image alt-text descriptive
- [ ] Custom OG image

- [ ] Definition in 1st H2
- [ ] 3+ structured bullet lists
- [ ] Comparison tables if relevant

- [ ] Mentions ChatGPT, Claude, Gemini, Perplexity
- [ ] Brand cited 2-4 times naturally
- [ ] Bottom line closing
- [ ] Q&A format for FAQ
