# Brand archetypes — adapt every recommendation

Pick the dominant archetype in the brand profile; note a secondary one if mixed. Never recommend a tactic that doesn't fit (no G2 for a creator, no Yelp for a dev tool, no Reddit promotion for a regulated brand).

| Archetype | Off-site sources to prioritise | Page types that win | Prompt mix leans to | Tone |
|---|---|---|---|---|
| **B2B SaaS** | G2, Capterra, TrustRadius, third-party "best X" lists, Reddit (r/SaaS + niche subs), LinkedIn articles, trade media, integration marketplaces | Comparison/alternatives, category page, pricing, integrations, case studies, original data | Category, comparison, use case | Direct, expert, specific |
| **Agency / services** | Clutch, Sortlist, DesignRush, case-study press, LinkedIn articles, podcasts | Service pages with category words, case studies with numbers, "how to choose a [service] agency", pricing ranges | Use case, local, comparison | Confident, outcome-focused |
| **E-commerce / DTC** | Trustpilot, niche subreddits, YouTube reviewers, lifestyle & specialist press, marketplaces, comparison/review blogs | Product pages with full specs & ingredients, buying guides, "X vs Y", FAQ on usage | Use case, educational, comparison | Warm, benefit-led, factual |
| **Dev tool / API** | GitHub (README, awesome-lists), Hacker News, dev.to, Stack Overflow, technical blogs, YouTube tutorials | Docs, quickstarts, benchmarks, "X vs Y", migration guides, changelog | How-to, comparison, educational | Terse, code-first |
| **Consumer app / brand** | Reddit, app stores, YouTube/TikTok creators, lifestyle press, Trustpilot | Feature pages, how-tos, comparisons, pricing | Educational, use case, branded | Warm, story-driven |
| **Local business** | Google Business Profile, Yelp/Tripadvisor/industry directories, local press, local subreddits | Location pages with real details (hours, prices, services), FAQs | Local ("near me", "in [city]"), branded | Friendly, location-first |
| **Creator / personal brand** | YouTube, podcasts, newsletters, Reddit, X/LinkedIn | Signature frameworks, about page with credentials, resource pages | Educational, personal | Personal, authentic |
| **Regulated (health, finance, legal)** | Authoritative editorial, professional bodies, .gov/.edu, Wikipedia (only if notable) | Expert-reviewed explainers with citations, reviewer bylines, disclaimers | Educational, branded | Cautious, sourced, no superlatives |

## Market specifics

- **France / EU**: track Mistral Le Chat in addition to ChatGPT, Gemini, Perplexity, Google AIO; write natively in French; € pricing; French review/press sources (e.g. Appvizer for software, Les Echos/Maddyness/Journal du Net for B2B tech, local PQR for local). Search Bing.fr and Google.fr results for retrieval checks.
- **Multi-market**: separate prompt sets per language/country; hreflang; localised comparison pages (competitors differ by country).

## Stage specifics

- **New brand (0 mentions)**: foundations first — crawlable site, one clear category page, 5–6 answer pages on real buyer questions, profiles on the 3 key review/directory sites, founder LinkedIn articles. Expect first mentions on long-tail/full-offer prompts within weeks; category shortlists take months.
- **Established brand, low AI share**: comparison pages + third-party list inclusion + review volume; fix misdescriptions.
- **Leader**: defend — accuracy monitoring, freshness, original data, YouTube.
