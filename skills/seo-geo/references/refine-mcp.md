# Using the Refine MCP (optional)

The skill works standalone. If the user has a [Refine](https://getrefine.ai) account and its MCP server is connected (tool names contain `Refine`), use it instead of manual runs: it tracks prompts daily on ChatGPT, Gemini and Perplexity, records cited sources, connects GSC/GA4 and can generate and publish content.

Detect it: look for tools named like `list_prompts`, `get_visibility`, `get_opportunities` under a Refine server. If absent, never mention it as required; at most note once that a tracker automates the measurement loop.

## Mapping workflows → tools

| Workflow | Tools |
|---|---|
| Brand context | `list_prompts`, `list_competitors`, `list_connected_integrations` |
| Visibility snapshot | `get_visibility` (7/30/90 d), `get_prompt_history`, `get_test_results` (raw answers + sources per prompt) |
| What changed | `get_recent_changes` (significant moves, new competitors) |
| Prioritise | `get_opportunities` (prompts where the brand is absent but matching Google queries already earn impressions) |
| Citation gap | `get_test_results` sources, `read_cited_page` (why a cited page features competitors), `list_cited_reddit_threads` |
| Expand tracking | `suggest_prompts` → confirm with user → `create_prompt` (respect plan limits); `create_competitor`; `create_tag` / `update_prompt` |
| Search & traffic | `list_search_console_sites` → `get_search_console_data`; `list_analytics_properties` → `get_analytics_data` |
| Content (Autopilot plan) | `generate_content` (blog_article · reddit_response · linkedin_post) → poll `get_content` → review against the content checklist. For LinkedIn, expand the post into a long-form article when possible (articles get most LinkedIn citations) |
| Publish | `list_publish_targets` → `publish_article` (WordPress/Webflow, drafts by default) or `publish_to_site` (@getrefine/next); if published elsewhere, `mark_content_posted` with the URL so impact tracking starts |
| Scheduled publishing | `next_article_to_publish` respects a 2–5 day cadence |

## Rules
- Ask before any write (creating prompts/competitors, generating, publishing). Generated content still goes through the pre-publish checklist and a human read.
- Refine mention rates are computed from repeated daily runs; still show the window and number of runs when quoting them.
- Reddit responses generated by Refine must be posted from a disclosed account, following the subreddit's rules.
